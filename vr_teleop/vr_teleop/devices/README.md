# devices/ — 입력 기기 (기기 하나만으로 하는 일)

기기마다 폴더 하나. 각 폴더에는 **그 기기 하나만으로 처리할 수 있는 것**만 둔다: SDK·드라이버 연결, 기기 원시 데이터를
읽고 `common/`의 표준 형식으로 바꾸는 것. 기기를 조합하는 처리(손등에 단 컨트롤러 → 손목, 글러브-컨트롤러 마운트
캘리브레이션)는 `teleop/`(실행 중 계산)과 `tools/calibration/`(캘리브레이션)에 둔다.

| 폴더 | 기기 | 내보내는 것 |
|---|---|---|
| `manus/` | Manus Metagloves Pro | 손가락 모양: 글러브 25관절 → 손목 좌표계의 OpenXR 손 관절 (위치 추적은 없음) |
| `metaquest/` | Meta Quest 3 | 컨트롤러·머리·손 추적 6D pose, 컨트롤러 버튼, XR 기준점 이동, 헤드셋 메뉴 START/STOP/RESET |

새 기기를 추가할 때: `devices/<기기>/`를 만들고, 원시 데이터 → 표준 형식 변환만 넣는다.
