# common/ — 기기 공통 규약

모든 기기가 텔레옵 쪽에 넘기는 **표준 손 표현**과 그 계산 도구. numpy / scipy만 쓴다.

| 파일 | 내용 |
|---|---|
| `openxr_hand.py` | OpenXR 손 관절 26개 이름(`HAND_JOINT_NAMES`), 손목 좌표 규약(+Y 손등, −Z 손가락 방향, X = Y × Z), 손바닥-아래 손목 좌표 만들기(`palm_down_frame`), 편 손 템플릿, 뼈 연결과 그리기용 점 |
| `rotation_utils.py` | 쿼터니언(wxyz) ↔ 회전행렬, 회전각, 평균 회전, 부호 있는 축 순열 맞추기 |

**표준 손 표현**: `{관절 이름: [x, y, z, qw, qx, qy, qz]}` (시뮬레이션 월드 좌표, 26개). Isaac Lab `OpenXRDevice`가
헤드셋 손 추적으로 주는 형식과 같아서, 손 추적용 리타게터가 글러브+컨트롤러 입력도 그대로 받는다.

**넣을 것**: 둘 이상의 기기나 모듈이 같이 쓰는 규약·수학. **넣지 말 것**: 특정 기기·시뮬레이터에 묶인 코드.
